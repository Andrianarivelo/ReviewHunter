The ReviewHunter Connector saves the article, book or web page you are viewing in Chrome, with its PDF, straight into your library. It downloads PDFs inside your browser, so papers you can open through your institution or a publisher account are captured too (the server alone cannot pass publisher bot protection).

Install (one time, about 1 minute)
  1. Open chrome://extensions in Chrome (type it in the address bar).
  2. Turn on Developer mode (top right).
  3. Click Load unpacked and select the folder below.
  4. Pin the ReviewHunter icon (puzzle icon, then the pin). Shortcut: Ctrl+Shift+Y.

ReviewHunter must be running for the connector to save (the icon turns grey otherwise). The server only accepts writes from the app itself and from browser extensions, never from ordinary websites.

The Word add-in inserts live citations and a bibliography from your library, in any of your citation styles, and renumbers everything when you edit (like the Zotero Word plugin).
