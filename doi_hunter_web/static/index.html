  • ReviewHunter reads a copy of zotero.sqlite; nothing is ever written to Zotero, so Zotero can stay open.

A shared library is a collection that several people read and edit together. It lives in a Google Drive folder shared with your colleagues: everyone can add papers, notes, tags and PDFs, and edits made at the same time on different fields are all kept.

How to invite people
  1. Click Open folder on the library, right-click it and choose Share (Google Drive), or share it from drive.google.com. Editor = can add and edit papers, Viewer = read only.
  2. Your colleague opens Shared with me on drive.google.com, right-clicks the folder and chooses Organize > Add shortcut to My Drive, so that Drive for desktop syncs it.
  3. In ReviewHunter they open Settings > Shared Libraries > Find in Drive and click Join.

Each person only writes files of their own inside the folder, so Drive never has two people saving the same file. Do not edit or move the files by hand. For large libraries, mark the folder Available offline in Drive so PDFs are already on disk.

The ReviewHunter Connector saves the article, book or web page you are viewing in Chrome, with its PDF, straight into your library. It downloads PDFs inside your browser, so papers you can open through your institution or a publisher account are captured too (the server alone cannot pass publisher bot protection).

Install (one time, about 1 minute)
  1. Open chrome://extensions in Chrome (type it in the address bar).
  2. Turn on Developer mode (top right).
  3. Click Load unpacked and select the folder below.
  4. Pin the ReviewHunter icon (puzzle icon, then the pin). Shortcut: Ctrl+Shift+Y.

ReviewHunter must be running for the connector to save (the icon turns grey otherwise). The server only accepts writes from the app itself and from browser extensions, never from ordinary websites.
